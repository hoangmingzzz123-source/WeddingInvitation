# Invitation fonts

Unmodified font files from Google Fonts, served locally for consistent Vietnamese glyphs on mobile.

- `wedding-sans-regular.ttf`: Be Vietnam Pro Regular (400).
- `wedding-sans-semibold.ttf`: Be Vietnam Pro SemiBold (600).
- `wedding-serif-regular.ttf`: Playfair Display Regular (400).
- `wedding-serif-italic.ttf`: Playfair Display Italic (400).

The CSS family aliases are `Wedding Sans` and `Wedding Serif`. The original names and copyright metadata inside the font files are unchanged.

Sources: https://fonts.google.com/specimen/Be+Vietnam+Pro and https://fonts.google.com/specimen/Playfair+Display.
Both fonts use the SIL Open Font License 1.1. Full licenses are included alongside the fonts.
